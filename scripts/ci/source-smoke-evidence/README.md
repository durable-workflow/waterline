   No execution inputs are selected or accepted by this source packet.

   starts exact-label cleanup 30 seconds before the ceiling. Every container has

   capabilities, no-new-privileges, PID/CPU/RAM/swap caps and bounded task writes.
   No host credentials, bind mounts, socket, published ports or external egress.
